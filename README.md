# YTmusicZ
YT Music advanced player

Based on WebView, this app allows you to use the full desktop interface on your phone. This setup enables advanced features, such as background playback and listening with the screen turned off.

This app is designed specifically for users who prefer the desktop appearance of YT Music. Additional features are optional and not actively planned.
